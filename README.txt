K.B. Bhabha Municipal General Hospital — Inventory Website

FILES
- index.html: hospital information homepage
- accessories.html: searchable accessories catalogue with category and stock filters
- admin.html: inventory dashboard, item form, stock issue form and reports
- common.js: inventory records, formatting and browser storage
- admin.js: dashboard operations and validation
- style.css: responsive website styling

RUN
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Open index.html in a browser.
4. Select Inventory Admin to open the login page.
5. Login credentials: username admin, password hospital123.

FEATURES
- Search and filter accessories
- Add, edit and delete inventory items
- Reorder levels and low-stock alerts
- Record stock issues with quantity validation
- Dashboard metrics and inventory valuation in Indian Rupees
- Issue history and CSV export
- Inventory records saved in this browser

IMPORTANT
This version stores data in the browser and uses a front-end login check. It is not suitable for real hospital operations or confidential data. A production system requires secure server-side authentication, a database, role permissions, audit logging, backups and authorization from the hospital. Verify all inventory information and clinical suitability before procurement or use.
